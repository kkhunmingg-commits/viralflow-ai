รับคลิปเดิมจาก Google Vids

คุณเป็นผู้อนุญาต Google และเลือกโปรเจกต์หนึ่งไฟล์ด้วยตนเอง การทดสอบนี้ไม่สร้างคลิปใหม่ ไม่โพสต์ และไม่แตะข้อมูล Production

กำลังตรวจความพร้อม

ตั้งค่าก่อนทดสอบ

  1. เปิด Google Drive API และ Google Picker API ใน Google Cloud project ที่คุณควบคุม
  2. สร้าง OAuth client สำหรับการทดสอบ Local แบบ Web application และเพิ่มบัญชี Pro เป็น Test user
  3. Authorized Origin: http://localhost:3020
    Redirect URI: http://localhost:3020/oauth/callback
  4. API key สำหรับ Picker ต้องจำกัดเฉพาะ Drive/Picker API และ referrer ของ Local กับ Google Picker ตามคู่มือ
  5. ตั้งค่า Local environment ตามเอกสาร แล้วเริ่มหน้าทดสอบใหม่ ห้ามส่งคีย์ในแชต

ผลตรวจไฟล์เดิม

    การตรวจรูปแบบไม่ใช่การรับรองภาพสินค้า เสียงภาษาไทย หรือนโยบาย คลิปยังต้องตรวจด้วยคนก่อนใช้จริง

    Full Auto Omni: ยังไม่ยืนยัน · ไม่บันทึกเข้าฐานข้อมูล · ไฟล์อยู่ในเครื่องเท่านั้น

    Token อยู่ชั่วคราวในหน่วยความจำ ตัวเลือกไฟล์ Google ต้องใช้ Token เฉพาะสิทธิ์ไฟล์ในหน่วยความจำ Browser ไม่มีการบันทึก Token ลงไฟล์หรือ Browser storage
