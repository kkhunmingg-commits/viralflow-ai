# ระบบออโต้กึ่งแมนนวล: Google Flow หลายบัญชี → คลังคลิป → โพสต์เอง (28 ต.ค. 2026)

สถานะ: **โค้ดพร้อม ทดสอบกับ Flow จำลองผ่าน ยังไม่ได้ลองกับ Flow จริง** (ยังไม่ใช้เครดิตจริงตามที่ตกลง) และ migration ยังไม่ได้ apply ขึ้นฐานข้อมูลจริง

## ทำงานอย่างไร

0. ระบบหลักคือ **สร้างคลิปฟรี** (`/post`, เมนู “สร้างคลิปฟรี & คลัง”) ไม่เสียเงินต่อคลิป ระบบเดิมที่จ่ายผ่าน API (fal / Wan / Flow API) ถูกพับไว้ล่างสุดเป็น “ระบบสำรอง” เท่านั้น `/library` พาไปหน้าเดียวกัน
   - แต่ละบัญชี TikTok ผูกบัญชี Google (Flow) ได้สูงสุด 5 บัญชี บัญชี Google ที่ผูกไว้ทำคลิปให้เฉพาะบัญชี TikTok นั้น (บังคับใน `claim_flow_clip`) จะผูกบัญชีเดียวที่เครดิตเยอะก็ได้
   - หน้าแสดงว่าเครื่องที่รัน worker ออนไลน์อยู่ไหม (worker ส่งสัญญาณทุกครั้งที่เช็กคิว)
1. เลือกบัญชี TikTok แล้วกดปุ่ม **ค้นหาสินค้าและสร้างคลิป** (หรือ **สร้างคลิปปั้นช่อง**) ครั้งเดียว
   - บัญชีช่วงขายของ (`effective_mode = AFFILIATE`): ระบบเลือกสินค้าคะแนนสูงสุดที่ยังขายอยู่และมีรูปที่ผ่านการตรวจสิทธิ์ (approved, ใช้เชิงพาณิชย์/โปรโมตได้, TikTok) แล้วใช้ Flow-native director วางฉาก+ท่ามือไม่ซ้ำกัน
     แหล่งสินค้าขายดีคือ TikTok Shop/Affiliate API เมื่อได้สิทธิ์ ระหว่างนี้ใช้สินค้าที่นำเข้าเอง (ไม่มี Kalodata)
   - บัญชีอุ่นเครื่องหรือยังไม่มีสินค้าที่มีรูป: คลิปปั้นช่อง (ฉากชีวิตประจำวัน ไม่มีสินค้า ไม่มีคำอ้าง)
   - จำนวนคลิป = เป้าต่อบัญชีวันนี้ (กดซ้ำจะเติมให้ครบเป้า ไม่ซ้อน)
2. คอมพิวเตอร์ของเจ้าของรัน `.\scripts\flow-farm-d.ps1` ค้างไว้ (โหมด watch) worker จะ
   - เปิด Chrome ของแต่ละบัญชี Flow แบบไม่โชว์หน้าจอ (หน้าต่างอยู่นอกจอ หรือ headless) เปิดเฉพาะตอนมีงาน
   - ใช้บัญชีตามลำดับที่ตั้งในหน้าคลัง **ใช้บัญชีแรกจนเครดิตหมดจริง** (Flow แจ้งเครดิตไม่พอ) แล้วย้ายบัญชีถัดไป
   - ถ้าทุกบัญชีเครดิตหมด → หยุด เก็บคลิปที่ทำได้ไว้ คลิปที่เหลือของวันนั้นเปลี่ยนเป็น “ข้าม: เครดิต Flow หมด”
     ตัวอย่าง: เป้า 15 คลิป ใส่ 3 บัญชี (บัญชีละ ~5) ได้ 15 / ใส่บัญชีเดียวได้ ~5 แล้วรอโพสต์ / บัญชีเครดิตเยอะใช้บัญชีนั้นจนหมดก่อน
   - **เน้นฟรี**: อ่านค่าเครดิตที่ Flow แสดง (“การสร้างจะใช้ 10 เครดิต”) ถ้าเกิน `FLOW_MAX_CREDITS_PER_CLIP` (ค่าเริ่ม 10 = Veo 3.1 - Lite x1) หรืออ่านไม่ได้ จะไม่กด Generate
   - กด Generate **ครั้งเดียวต่อคลิป** ถ้ากดแล้วมีปัญหา จะไม่กดซ้ำอัตโนมัติ (บันทึกใน `workspace/farm-journal`)
   - ตรวจไฟล์: MP4 จริง มีวิดีโอ แนวตั้ง 9:16 แล้วอัปโหลดตรงเข้า Storage ส่วนตัว เซิร์ฟเวอร์ตรวจซ้ำ (ขนาด, ลายเซ็น MP4, checksum, ไม่ซ้ำไฟล์เดิม) แล้วลบไฟล์ในเครื่อง
3. คลิปเข้าคลังสถานะ **พร้อมโพสต์** ดูตัวอย่าง คัดลอกแคปชัน ดาวน์โหลด MP4 หรือ **ตั้งเวลา** (ถึงเวลาจะขึ้นป้าย “ถึงเวลาโพสต์แล้ว”)
4. โพสต์เองใน TikTok (เปิดป้ายเนื้อหา AI) แล้วกด **โพสต์แล้ว · ลบไฟล์** ระบบลบ MP4 ออกจาก Storage ทันที เหลือแต่ประวัติ
   เมื่อ TikTok อนุมัติ Direct Post API ค่อยต่อให้คลิปที่ตั้งเวลาไว้ส่งขึ้นเองแล้วลบไฟล์ (ยังไม่ได้ทำในรอบนี้)

## ติดตั้งครั้งแรก

1. Apply migration `supabase/migrations/20261028150000_flow_farm_semi_auto.sql` (ตาราง `flow_accounts`, `flow_clips`, `flow_worker_status`, ฟังก์ชัน `claim_flow_clip`, `skip_unreachable_flow_clips`)
2. ตั้ง env ฝั่งเซิร์ฟเวอร์: `FLOW_WORKER_TOKEN` (สุ่มยาว 32+ ตัว) และ `FLOW_WORKER_OWNER_ID` (id ผู้ใช้ของเจ้าของ)
3. ในเครื่อง: คัดลอก `workers/flow-browser/farm.env.example` เป็น `farm.env` ใส่ URL และ token เดียวกัน
4. หน้า `/post` → เลือกบัญชี TikTok → ผูกบัญชี Google ตามลำดับที่อยากให้ใช้ (สูงสุด 5) แล้วคัดลอก “รหัสสำหรับล็อกอิน” ของแต่ละบัญชี
5. ล็อกอินแต่ละบัญชีครั้งเดียว: `.\scripts\flow-farm-d.ps1 -Login <id>` (หน้าต่างโชว์ ล็อกอิน Google ตั้ง Veo 3.1 - Lite, 9:16, x1 แล้วกด Enter)
6. ตรวจโดยไม่ใช้เครดิต: `.\scripts\flow-farm-d.ps1 -Probe` (ต้องเห็น signedIn, promptBox, generateButton = true และ cost = 10)
   และ `.\scripts\flow-farm-d.ps1 -DryRun` (เตรียมคลิปจริง 1 งานใน Flow แล้วหยุดก่อนกด Generate)
7. ใช้งานจริง: `.\scripts\flow-farm-d.ps1` ค้างไว้ แล้วกดปุ่มในหน้าคลัง

ถ้าหน้า Flow เปลี่ยน ให้ใส่ selector ใหม่ใน `workers/flow-browser/selectors.json` ใต้ key `"farm"` (`prompt`, `generate`, `settingsChip`, `imageInput`, `newProject`)

## สิ่งที่ยังไม่ได้พิสูจน์ / ความเสี่ยง

- ยังไม่ได้ลองกับหน้า Flow จริง: ตัวเลือกปุ่มเดาจากภาพหน้าจอ Flow ภาษาไทยที่บันทึกไว้ (`.runtime/flow-generate-ready.jpg`) ต้องรัน `-Probe` / `-DryRun` ก่อน และลองสร้างจริง 1 คลิป (10 เครดิต) เมื่อเจ้าของอนุมัติ
- การดึงวิดีโอใช้ `<video src>` ที่ปรากฏใหม่ ถ้า Flow ไม่ใส่ src ให้ ต้องเพิ่มการกดปุ่มดาวน์โหลด
- Google อาจไม่ยอมให้ล็อกอินใน Chrome ที่ควบคุมด้วย Playwright หรือขอ CAPTCHA ระบบจะหยุดบัญชีนั้น ไม่หลบเลี่ยง
- การใช้หลายบัญชีเพื่อเพิ่มเครดิตฟรีอาจขัดเงื่อนไขของ Google และเสี่ยงบัญชีถูกจำกัด เป็นการตัดสินใจของเจ้าของ
- คลิปที่ worker หายกลางทาง (เกิน 20 นาที) เปลี่ยนเป็น “สร้างไม่สำเร็จ” ให้ไปดูในคลัง Flow เอง ไม่สร้างใหม่อัตโนมัติ
