# Drama Studio 2.0 (ละครซีรีส์)

ละครสั้นต่อเนื่องที่ AI เขียนและกำกับเอง ผลิตจากคลิป Google Flow ฟรีผ่านระบบ Flow Farm เดิม

## ทำงานอย่างไร

1. เจ้าของเลือกแนว (สยองขวัญ แอ็กชัน ตลก โรแมนติก สืบสวน แฟนตาซี) ช่อง TikTok บัญชี Google หลัก บัญชีซ่อม (ไม่บังคับ) จำนวนตอน และช็อตต่อตอน (ค่าเริ่มต้น 5 ช็อต ≈ 40 วิ) ที่แท็บ **ละคร** ในหน้า `/post?studio=drama` (`/drama` เดิมพาไปที่นี่)
2. **Showrunner** (`src/features/drama/showrunner.ts`) สร้าง "คัมภีร์ของเรื่อง" ครั้งเดียว: ตัวละคร 3 ตัว (หน้าตา ชุด เสียง นิสัย ความลับ) สถานที่ 3 แห่ง สิ่งของสำคัญ ความจริงที่ซ่อน และตอนจบ พร้อมแผนทั้งซีซัน (เปิดเรื่อง → จุดเปลี่ยน → ไคลแมกซ์ → ตอนจบ) ตอนจบจึงล็อกไว้ตั้งแต่วันแรก
3. ทุกวัน ระบบเขียนตอนใหม่จาก **ความทรงจำของเรื่อง** (StoryState: ใครบาดเจ็บ/เปียก เบาะแสที่เผยแล้ว ฉากที่ใช้ไปแล้ว ไคลแมกซ์ค้างของตอนก่อน) ช็อตแรกต่อจากฉากค้างของเมื่อวาน ช็อตสุดท้ายคือฉากค้างใหม่
4. ช็อตถูกส่งเข้าคิว `flow_clips` เดิมทีละช็อตตามลำดับ (`kind = DRAMA_SHOT`) เครื่อง Flow worker ตัวเดิมสร้างคลิปโดยไม่ต้องแก้โค้ด worker
5. เมื่อช็อตเสร็จ เซิร์ฟเวอร์ดึงเฟรมสุดท้ายด้วย ffmpeg ใช้เป็นภาพอ้างอิงของช็อตถัดไป ส่วนเฟรมสุดท้ายของช็อตแรกในตอนที่ 1 กลายเป็น **ภาพหลักของตัวละคร** ที่ทุกตอนใช้เริ่มต้น
6. ครบทุกช็อต เซิร์ฟเวอร์ตัดต่อเป็นตอนเดียว 720x1280 พร้อมซับไทย ป้ายชื่อเรื่อง/ตอน และ "ติดตามตอนต่อไป" แล้วเก็บเข้าคลังเป็นคลิป `kind = DRAMA` รอเจ้าของตรวจและโพสต์เอง (ไม่โพสต์อัตโนมัติ)

ตัวขับเคลื่อนคือ `tickOwner` ที่รันหลัง worker เช็กบัญชี (`GET /api/flow-worker/accounts` ทุกนาที) และหลังส่งคลิปเสร็จ ไม่มี cron เพิ่ม

## ความต่อเนื่อง

- คำบรรยายตัวละครภาษาอังกฤษถูกล็อก และใส่ซ้ำคำต่อคำในทุก prompt
- ภาพอ้างอิง: ช็อตแรกของทุกตอนใช้ภาพหลัก ช็อตถัดไปในที่เดิมใช้เฟรมสุดท้ายของช็อตก่อน เปลี่ยนสถานที่ใช้ภาพหลัก
- สภาพตัวละคร (แผล เสื้อเปียก) ถูกจำและใส่ใน prompt ตอนต่อ ๆ ไป

## บัญชีหลัก บัญชีซ่อม และการตรวจช็อต

- บัญชีหลัก = บัญชี Google ที่ผูกในแท็บคลิป (`purpose = CLIP`) 1 บัญชีล็อกกับละครที่กำลังผลิตได้ 1 เรื่อง (unique index `drama_series_one_per_account`) และยังทำคลิปปกติได้: `claim_flow_clip` ให้ทำตอนละครของวันนั้นก่อน (ระหว่างถ่ายทำ หรือตอนของวันนี้ถึงเวลาแต่ยังไม่เริ่ม) แล้วค่อยรับคลิปปกติ
- บัญชีซ่อม = บัญชี Google แยก (`purpose = REPAIR`, ไม่ผูกช่อง TikTok) เพิ่มในแท็บละคร ใช้ร่วมได้ทุกเรื่อง และรับเฉพาะช็อตที่ส่งมาให้ซ่อม ไม่ถูกดึงไปทำคลิปปกติ
- ช็อตละครระบุ `flow_clips.required_flow_account_id` worker ทุกตัวเดิมใช้ได้ทันที การแจกคิวทำในฐานข้อมูลทั้งหมด
- ทุกช็อตที่ได้มา เซิร์ฟเวอร์ตรวจด้วย ffmpeg (`checkShot`): ไฟล์เสีย ไม่มีภาพ สั้นกว่า 4 วิ จอดำ ≥80% ภาพค้าง ≥90% ถือว่าเสีย
- ช็อตเสียหรือ Flow สร้างไม่สำเร็จ: ส่งไปบัญชีซ่อม (ไม่มีบัญชีซ่อมก็ลองบัญชีหลัก) รวมสูงสุด 4 ครั้งต่อช็อต แล้วตอนนั้นหยุดรอเจ้าของ กด "ลองใหม่" หรือ "ข้ามช็อตนี้" ได้
- เครดิตบัญชีหลักหมด: ย้ายไปบัญชีซ่อมทันทีถ้ายังมีเครดิต (ไม่นับเป็นความพยายาม) ไม่งั้นรอเช้าวันใหม่ (เวลาไทย) ไม่ข้ามเนื้อเรื่อง
- ข้อจำกัด: ตรวจได้เฉพาะความเสียทางเทคนิค ยังไม่ตรวจว่าภาพตรงกับบทหรือไม่ (ต้องใช้ AI ตรวจภาพแบบเสียเงิน)

## ตรวจทุกตอนก่อนไปต่อ

- ตอนที่ตัดเสร็จไปอยู่ในคลังพร้อมสถานะ "รอคุณตรวจ" (`drama_episodes.review = PENDING`) การ์ดของเรื่องมีคลิปให้ดูและปุ่ม **ผ่าน** / **ไม่ผ่าน**
- ผ่าน: ความทรงจำของเรื่องเดินต่อ (`story_state`, `next_episode_number`) ตอนถัดไปเริ่มวันถัดไป หรือทันทีถ้าวันนี้ยังทำได้อีกตอน
- ไม่ผ่าน: เอาคลิปออกจากคลัง ลบตอนนั้น และถ่ายตอนเดิมใหม่ตั้งแต่พรุ่งนี้ (`drama_series.redo_on`) บทเดิม เทคใหม่ ถ้าเป็นตอนที่ 1 จะสร้างภาพหลักของตัวละครใหม่ด้วย
- ระหว่างรอตรวจหรือรอวันถ่ายใหม่ บัญชีหลักทำคลิปปกติได้

## จบซีซันแล้วเริ่มเรื่องใหม่

- เมื่อตอนสุดท้ายผ่าน การ์ดของเรื่องขึ้นปุ่ม **สร้างเรื่องใหม่** สร้างเรื่องใหม่แนวเดิม ช่องเดิม บัญชีหลัก/ซ่อมเดิม (`previous_series_id` ชี้เรื่องก่อน) และเริ่มตอนที่ 1 ทันที
- เลือกเรื่องที่ยังไม่เคยทำก่อน (`pickStory`) ครบทุกเรื่องแล้ววนกลับไปเรื่องที่ทำนานที่สุด ปัจจุบันมีแนวละ 2 เรื่อง (`genres.ts` + `more-stories.ts`)
- ท้ายทุกตอนขึ้น "กดติดตามไว้ เพื่อดูตอนต่อไป" (ตอนจบ: "จบบริบูรณ์ กดติดตามไว้ เพื่อดูเรื่องใหม่") ทั้งในคลิปและแคปชัน

## เครดิตหมดและช็อตพัง (ตัดต่อ)
- ตัดต่อล้ม: ลองใหม่สูงสุด 3 ครั้ง เซิร์ฟเวอร์ดับกลางทางจะเริ่มตัดใหม่หลัง 10 นาที

## ไม่กระทบระบบเดิม

- โควตาคลิปรายวันของ Growth/Affiliate นับเฉพาะ `GROWTH`, `AFFILIATE`
- ช็อตย่อย (`DRAMA_SHOT`) ไม่โผล่ในคลัง หน้าวันนี้ หรือระบบเรียนรู้ เห็นเฉพาะตอนที่ตัดเสร็จ
- ช็อตย่อยถูกลบไฟล์หลังตัดต่อ เหลือแค่ภาพหลักของตัวละคร

## ต้องทำก่อนใช้งานจริง

1. รัน `supabase/migrations/20261104120000_drama_studio.sql` `20261104160000_drama_accounts.sql` และ `20261104180000_drama_repair_accounts.sql` และ `20261104200000_drama_review.sql` ใน Supabase
2. Deploy ขึ้น Vercel (ต้องได้รับอนุมัติจากเจ้าของ)
3. ปรับเทียบ Flow: ตรวจว่าโหมดที่ worker ใช้ถือภาพแนบเป็น "เฟรมแรก" หรือ "ส่วนผสม" ลองตอนแรกของแนวหนึ่งแล้วดูความต่อเนื่องของหน้าตาตัวละคร

## ข้อจำกัด

- บทเขียนด้วยกฎ + คลังเนื้อหาที่เตรียมไว้ (ฟรี คาดเดาได้ ทดสอบได้) ยังไม่ใช้ LLM ถ้าต้องการบทที่หลากหลายกว่านี้ เพิ่ม writer แบบ LLM ได้ในอนาคต (มีค่าใช้จ่าย ต้องอนุมัติ)
- เสียงพูดไทยของ Veo ยังไม่แน่นอน จึงฝังซับไทยทุกช็อต
- หน้าตาตัวละครคงที่ได้ดีที่สุดเท่าที่ Flow + ภาพอ้างอิงทำได้ ไม่ใช่การล็อกใบหน้า 100%
- ต้องปฏิบัติตามเงื่อนไขของ Google Flow/Veo และ TikTok (ติดป้ายเนื้อหา AI เมื่อโพสต์)
